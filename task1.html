Task 1. Selectors and CSS

Part 1. Getting Started with jQuery

Elements on the page

This paragraph is selected by its id.

This paragraph is selected by its class.

And this one has the same class.

Every blockquote is selected by its tag name.

Selectors used here

  • $("#byId") selects one element by its id.
  • $(".by-class") selects every element with that class.
  • $("blockquote") selects every element with that tag name.
  • .text() writes plain text, .html() writes markup that the browser renders.
  • .css() changes one property or a whole object of properties.
