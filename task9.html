Task 9. Sequential Animations

Part 4. Animations

The steps

  1. Move to the right.
  2. Move down.
  3. Shrink to a smaller square.
  4. Return to the original position and size.

How it works

Every .animate() call on the same element is put into the animation queue, so the four steps run one after another without any timers. The callback of each step writes the current stage into the line under the stage.
