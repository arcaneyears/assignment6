Task 4. Slide Methods

Part 2. jQuery Effects

Collapsible panel

This block is collapsed and expanded with the slide methods. The height of the block is animated, so the content looks as if it slides out of the page and back into it.

The second part of the text is here only to make the panel taller, so the animation is easier to see.

How it works

.slideUp() animates the height of the element down to zero and hides it, .slideDown() brings it back, and .slideToggle() switches between the two. The callback function passed as the second argument runs when the animation ends.
